# CyberMind

CyberMind is a simple Android quiz app made using Kotlin in Android Studio. The app helps users learn the difference between real life hacks and internet myths through fun quiz questions.

---

# App Features

- Quiz questions
- Multiple choice answers
- Score screen
- Review screen
- Easy navigation
- Simple user interface

---

# Purpose of the App

The purpose of this app is to help users think carefully about information found online. Some life hacks on the internet are useful, while others are fake or unsafe. CyberMind helps users test their knowledge in a fun and interactive way.

---

#  Design

The app was designed to be simple and easy to use.

Design choices:
- Clear buttons
- Easy-to-read text
- Simple layouts
- Smooth screen navigation
